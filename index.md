## Open source

### NEPSE Trade Journal

A full-stack trading journal for Nepal Stock Exchange (NEPSE) traders: plan, execute, and review trades, keep a daily journal, track a portfolio, and see analytics like win rate, P&L, and expectancy.

- Code: https://github.com/bijay3030/nepse-trade-journal
- Stack: Ruby on Rails 8 (API), PostgreSQL, ActionCable, Devise + JWT, React 19, TypeScript, Tailwind CSS
- Trade lifecycle modeled as Plan → Execute → Result, with automatic portfolio updates
- Live prices over ActionCable WebSockets, with polling fallback
- JWT authentication (Devise) on a Rails API; React Query on the client
